# Skill: layout หุ่นยนต์ 4 แกนใน SolidWorks 2023

## ภาพรวมโปรเจกต์
หุ่นยนต์ตั้งโต๊ะ/ตั้งพื้นขนาดเล็ก 4 แกน + กริปเปอร์ ใช้มอเตอร์ closed-loop NEMA23 ที่ A1-A3 และ NEMA17 ที่ A4/กริปเปอร์

| แกน | หน้าที่ | ชุดขับ |
|---|---|---|
| A1 | เลื่อนขึ้นลง (Z) | NEMA23 + เกียร์ 5:1 + เบรก 24V -> พิเนียน M1.5 -> เฟืองสะพาน 15x15 บนรางเลื่อน HGR15 |
| A2 | หมุนข้อ 1 | NEMA23 + เกียร์ 10:1 + ลูกปืนแท่นหมุน Ø150 |
| A3 | หมุนข้อ 2 | NEMA23 + เกียร์ 10:1 + ลูกปืนแท่นหมุน Ø150 |
| A4 | หมุนข้อมือ | NEMA17 + เกียร์ 5:1 |
| G | จับ | NEMA17 + เฟืองสะพานเล็ก (3D print) |

ไฟล์ในโฟลเดอร์นี้
- `build_robot_arm.py`  สคริปต์หลัก (พารามิเตอร์อยู่ใน `PARAMS` ด้านบนไฟล์)
- `export_step.py`  ส่งออก **STEP assembly** (41 ชิ้น มีชื่อและสี) ไม่ต้องมี SolidWorks  `pip install cadquery` แล้วรัน `python export_step.py` เปิดใน SolidWorks/Fusion/FreeCAD ได้ทันที (เป็นของแข็ง ไม่ใช่โมเดลพารามิเตอร์) ตรวจแล้วอ่านกลับได้ครบทุกชิ้น ปริมาตรตรงกับสคริปต์ 0.00%
- `export_dxf.py`  ส่งออกแบบ 2 มิติ **DXF** (3 มุมมอง + ขนาดหลัก + ตารางชื่อแบบ) `pip install ezdxf` เปิดใน AutoCAD ได้ (DWG เขียนตรงไม่ได้ ให้ Save As จาก AutoCAD)
- `SKILL.md`  ไฟล์นี้

ข้อมูลประกอบอยู่ใน Excel `robot_arm_BOM_v3.xlsx` (BOM 32 รายการ, สรุปงบ, รายการต้องเช็ค, แผ่นคำนวณ) ถ้าเปลี่ยนขนาด ให้เปิดแผ่น "คำนวณแกน Z-A2-A3" แก้ช่องสีเหลืองให้ตรงกัน (ส่วน 6 ของแผ่นนั้นรับค่าจาก dry-run ของสคริปต์)

## ขนาดเริ่มต้น (ตามรูปแบบล่าสุดของผู้ใช้)
| รายการ | ค่า |
|---|---|
| เสา | 4080 สูง 1,500 mm บนแผ่นฐาน 220×220 |
| ราง / ช่วงชัก Z | HGR15 ยาว 1,300 mm / ตั้งไว้ 900 mm (รางให้ได้ ~1,084 mm) |
| แคร่ | แผ่น 160×200×10 mm |
| ลิงก์ 1 | 8020 (วาง 80 ตั้ง) ระยะศูนย์กลาง 550 mm |
| ลิงก์ 2 | 4040 ระยะศูนย์กลาง 450 mm (ผู้ใช้ยืนยันแล้ว: ตัดจากท่อน 4040 ที่สั่งไว้) |
| ระยะเอื้อมรวม | 1,000 mm |
| ฐาน | 4040 กรอบ 450×450 mm |
| ขนาดรวมที่สร้างได้ | กว้าง 450 × สูง 1,580 × ลึก 1,208 mm มวล ~32 kg |

## ระบบพิกัด (mm)
X = ขวา, Y = ขึ้น (พื้นโต๊ะ Y=0), Z = ทิศที่แขนยื่นออก
กึ่งกลางเสาอยู่ที่ X=0 และผิวหน้าเสา (ด้านรางเลื่อน) อยู่ที่ Z=0
ทุกชิ้นสร้างให้ origin ของ part อยู่ที่ศูนย์กลางตัวชิ้นงาน (extrude แบบ Mid Plane) ดังนั้นพิกัดใน `BOM_layout.csv` คือพิกัดศูนย์กลางชิ้นงานใน assembly

## ขั้นตอนทำงาน (ให้ทำตามลำดับ)

1. **ตั้งพารามิเตอร์**  แก้ `PARAMS` หรือใช้ `--set ชื่อ=ค่า` เช่น `--set L1=320 --set stroke=800`
2. **รัน dry-run ก่อนเสมอ** (ไม่ต้องมี SolidWorks รันบน Linux/Mac ได้)
   `python build_robot_arm.py --dry-run`
   สคริปต์จะ: คำนวณตำแหน่ง, เช็คช่วงชักไม่เกินรางและเฟืองสะพานยาวพอ, **ตรวจการชนด้วย Python (AABB)**, ประเมินมวล, **วิเคราะห์โหลดคร่าว ๆ** (พลิกคว่ำ, เสาแอ่ง, แรงบิดมอเตอร์ A2/A3, โมเมนต์ลูกปืน), ส่งออก `BOM_layout.csv` + `params_used.json`
   ถ้าเจอคู่ที่ชนกัน สคริปต์จะหยุด ให้แก้ขนาดจนไม่ชน (ผิวสัมผัสกันได้ ซ้อนทับไม่ได้)
3. **รันจริงบน Windows ที่มี SolidWorks 2023 + `pip install pywin32`**
   `python build_robot_arm.py`
   ผลลัพธ์อยู่ใน `output/robot_arm_<เวลา>/` (part ทีละไฟล์ + `robot_arm_layout.SLDASM` + `build_log.txt`)
4. **ตรวจใน SolidWorks**  เปิด assembly ดูสายตา, ดู Evaluate > Interference Detection, ดู `build_log.txt` ว่าทุกแถว component ขึ้น OK
5. **ปรับมวล**  placeholder (มอเตอร์ เกียร์ ลูกปืน กริปเปอร์) ใน SolidWorks มีมวลจากปริมาตรซึ่งไม่ตรงของจริง ให้ใช้ Evaluate > Mass Properties > Override Mass Properties ตามคอลัมน์ `มวล_kg` ใน `BOM_layout.csv` แล้วนำมวลรวมที่แกน Z (กลุ่ม `Z`) ไปใส่แผ่นคำนวณใน Excel
6. **แทน placeholder ด้วยไฟล์ STEP ของผู้ผลิต**  ทำมือใน SolidWorks (Replace Components) หลังได้ datasheet จริง
7. **ใส่ mate ภายหลัง** ถ้าต้องการจำลองการเคลื่อนที่ (ตอนนี้ทุก component ถูก fix ที่ตำแหน่ง home เพื่อให้ layout นิ่ง)

## กฎความปลอดภัย (อ้างอิง skill `solidworks-com-safety-rules`)
- **ห้ามเขียนทับไฟล์เดิม**  สคริปต์สร้างโฟลเดอร์ใหม่ทุกครั้ง และปฏิเสธถ้าโฟลเดอร์มีไฟล์อยู่แล้ว
- **ห้ามเขียน `Transform2`**  ใช้ `AddComponent5` วางที่พิกัดตอนใส่ แล้วอ่าน `Transform2.ArrayData` กลับมาเทียบ (ตำแหน่งต้องตรงภายใน 0.05 mm)
- **ห้าม `Save`/`SaveAs3` assembly ก่อนตรวจ**  ถ้าตำแหน่งผิดหรือมี interference ใน SolidWorks จะไม่เซฟ assembly
- **ปิดเอกสาร part ทุกตัวหลังสร้าง**  ไม่ทิ้งไฟล์ค้างเปิดไว้ (ไม่งั้น Save ของ assembly อาจเป็นสีเทา)
- ทุกค่าที่ส่งเข้า API เป็น **เมตร**  สคริปต์หาร 1000 ให้แล้ว
- ผลลัพธ์ของ `Save3`/`SaveAs3` เป็น tuple ใช้ `"%r" % (res,)` ตอน log

## ข้อจำกัดที่ต้องรู้
- **สคริปต์ผ่านการทดสอบเฉพาะส่วน Python** (คำนวณ ตรวจชน ส่งออก และตรรกะการสร้าง/เซฟด้วย COM จำลอง) **ยังไม่เคยรันกับ SolidWorks จริง** ถ้าเจอ error ให้เริ่มจาก `build_log.txt` และ `references/troubleshooting.md` ของ skill `solidworks-2023-automation`
- จุดที่เสี่ยงต่อชื่อ/พารามิเตอร์ API มากที่สุด: `FeatureExtrusion3` (23 พารามิเตอร์), `SetMaterialPropertyName2` (path ของ sldmaterials.sldmat), `InterferenceDetectionManager` ฟังก์ชันเหล่านี้ห่อ try/except ไว้แล้ว แต่ถ้า extrude ล้มเหลวให้ record macro ใน SolidWorks แล้วเทียบ
- ชื่อ plane ค่าเริ่มต้นเป็นภาษาอังกฤษ (Front/Top/Right Plane) ถ้าติดตั้งภาษาอื่น สคริปต์จะ fallback ใช้ลำดับ 3 ระนาบแรกในฟีเจอร์ทรี
- เรขาคณิตเป็นทรงกล่อง/ทรงกระบอกทึบหรือกลวงแบบง่าย: โปรไฟล์ 4040/4080 เป็นท่อสี่เหลี่ยมผนัง 4 mm (มวลประมาณ 1.5 kg/m ใกล้ของจริง ไม่มีร่อง T), พิเนียนโมเดลที่ขนาดรากฟัน ไม่มีฟัน, บล็อกรางโมเดลเฉพาะส่วนเหนือหัวราง, แผ่นแคร่ยังไม่เจาะรู (เพลาเกียร์ A1 ทะลุแผ่นแบบไม่มีรูในโมเดล)
- ยังไม่มี: โซ่ร้อยสาย, ตู้คอนโทรล, เซนเซอร์, ฉากเสริมเสา, ตัวกันชนทางกล, ท่าทางหมุนของ A2-A4 (โมเดลอยู่ท่า home คือแขนตรงไปข้างหน้า)
- ตัววิเคราะห์โหลดเป็นการประมาณ: ใช้มวล placeholder, คานเสาแบบกลวงผนัง 4 mm (โปรไฟล์จริงมีร่อง T), ไม่รวมความอ่อนของรางบล็อกและลิงก์ ใช้เปรียบเทียบตัวเลือกได้ แต่ยังไม่ใช่ผลวิเคราะห์ละเอียด (ควรทำ SolidWorks Simulation ก่อนสรุปความแม่นยำ)

## รายการต้องเช็คก่อนสั่งของ (ผลจากการคำนวณ)
1. **พิเนียน 16 ฟัน M1.5 รู Ø14 + ร่องลิ่ม ผนังเหลือ ~0.8 mm** บางเกินไป ให้ใช้ 20 ฟันขึ้นไป (`pin_z=20` เป็นค่าเริ่มต้นในสคริปต์) แล้วแจ้งร้าน Mana Machinery เปลี่ยนรายการ 16
2. ท้ายมอเตอร์ closed-loop มี encoder อยู่ ตรวจว่าติดเบรกท้ายมอเตอร์ได้หรือไม่ (โมเดล `a1_brake` ใช้ตรวจที่ว่างด้านหลังเท่านั้น)
3. ช่วงชัก Z ที่รางให้ได้ตามค่าปัจจุบัน ~1,084 mm (ตั้งใช้ 900 mm) เฟืองสะพาน 1 ท่อน 1,000 mm พอ ไม่ต้องต่อ 2 ท่อน
4. ส่งไฟล์ DXF/STEP ของแผ่นอลูมิเนียมให้ ABT Metalwork หลังยืนยันขนาด (ต้องเจาะรูแผ่นแคร่/แท่นรับแขน/แผ่นฐานเพิ่มจากโมเดลตั้งต้น)
5. **A2 แรงบิดไม่พอที่ขนาดนี้** เกียร์ 10:1 ที่ α = 5 rad/s² ปลอดภัยเพียง ~0.6 เท่า (α ที่ปลอดภัย 2 เท่า ≈ 1.45 rad/s² หมุน 90° ≈ 2.1 วินาที) ทางเลือก: เกียร์ 20:1, ลดมวลปลายแขน, หรือยอมรับท่าทางช้า (ลองด้วย `--set a2_ratio=20`)
6. **เสา 4080 แอ่งตัว** ปลายแขนตกจากการแอ่งของเสา ~2.8 mm กลางช่วงชัก ถึง ~5 mm บนสุด (เสาดัดรอบแกนอ่อนความลึก 40 mm) พิจารณาค้ำหลังเสาหรือโปรไฟล์ที่ลึกขึ้น
7. **ฐานพลิกคว่ำ** ปลอดภัย ~2.5 เท่าเมื่อแขนเหยียดตรง ควรยึดฐานกับโต๊ะ/พื้น
8. ลูกปืนแท่นหมุน Ø150 ต้องรับโมเมนต์สถิต ~51 N·m (A2) และ ~13 N·m (A3) เทียบกับ datasheet ก่อนสั่ง

## วิธีขยาย
- เพิ่มชิ้นส่วน: เพิ่ม `add(...)` ใน `build_design()` ระบุ `file` ซ้ำได้ถ้าเรขาคณิตเหมือนกัน (ใช้ไฟล์ part เดียว insert หลายตำแหน่ง) สคริปต์จะเช็คให้ว่าเรขาคณิตของไฟล์เดียวกันต้องตรงกัน
- เปลี่ยนท่าทาง (หมุน A2/A3): ต้องใช้ mate แบบ concentric + coincident ตามคำแนะนำใน `references/assembly.md` ไม่ใช่เขียน transform
- ถ้ามีการแก้ assembly ที่มีอยู่แล้ว ให้ **ก๊อปสำรองก่อน** และตรวจ interference ทั้ง assembly เทียบกับค่าก่อนแก้ ก่อน `Save3` ทุกครั้ง
